## 1️⃣ Agent-Reach ⭐ 85K

**作者：** Panniantong

**一句话：** 一个命令让 AI 读遍全网社媒，零 API 费！

### 是干嘛的？

- 自动爬取小红书、知乎、微博、Twitter 等全网社媒
- 不需要 API Key，零成本
- 让 AI 帮你读遍全网你关心的话题
- 可以做舆情监控、竞品分析、内容选题

### 适合谁用？

- 自媒体博主找选题
- 产品经理做竞品分析
- 运营做舆情监控
- 普通用户想追踪某个话题的全网讨论

## 2️⃣ career-ops ⭐ 72.5K

**作者：** career-ops-hq

**一句话：** 开源 AI 求职助手：扫岗 → 改简历 → 追投递！

### 是干嘛的？

全自动求职流水线：
1. **扫岗**：自动爬取 Boss 直聘、猎聘、LinkedIn 等招聘网站
2. **改简历**：根据岗位 JD 自动优化你的简历
3. **追投递**：自动跟进投递状态，写跟进邮件

### 适合谁用？

- 正在找工作的朋友
- 想跳槽的打工人
- 留学生找实习

## 4️⃣ i-have-adhd ⭐ 50.5K

**作者：** ayghri

**一句话：** 专治 AI 啰嗦，逼它先给结论！

### 是干嘛的？

- 一个浏览器插件/脚本
- 强制所有 AI（ChatGPT/Claude/DeepSeek）先给结论
- 再展开细节，不要废话
- 适合 ADHD 注意力缺陷的人，或者只是想要高效回答的人

### 为什么火？

太真实了！谁没被 AI 的长篇大论折磨过？
"请用 30 个字告诉我答案，不要废话！"

## 6️⃣ colibri ⭐ 37.2K

**作者：** JustVugg

**一句话：** 纯 C 零依赖，本地跑大模型！

### 是干嘛的？

- 用纯 C 写的大模型推理引擎
- 零依赖，不需要 Python、不需要 PyTorch
- 编译出来就是一个单文件
- 可以在非常弱的设备上跑小模型

### 为什么火？

- 极简！只有 C 语言和标准库
- 部署超简单，拷过去就能跑
- 适合嵌入式、路由器、旧手机跑模型
